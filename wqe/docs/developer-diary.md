# Дневник разработчика

## Этап 1. Идея
Выбрана идея коммерческой CS2-платформы по типу FACEIT: матчмейкинг, ELO, Premium, турниры и заявки.

## Этап 2. Распределение ролей
- UX-аналитик: сценарии, персоны, структура.
- UI-дизайнер: тема Steel Wings, логотип, карточки.
- Frontend-разработчик: React/Vite, компоненты, страницы.
- Backend-разработчик: имитация backend через localStorage.
- Тестировщик/менеджер: проверка сценариев и документация.

## Этап 3. Проектирование
Составлена карта сайта, сценарии и дизайн-документ. Принята гибридная структура: игровой сервис + коммерческие страницы + документы проекта.

## Этап 4. Frontend
Сайт разделён на отдельные файлы: pages, components, data, utils. Добавлена адаптивность.

## Этап 5. Backend
Реализована имитация backend: пользователи, роли, сессия, новости, обращения, матчи, ELO и задания.

## Этап 6. Тестирование
Проведены 5 тестов. После тестов усилены CTA, добавлены контакты, FAQ, блок доверия, админ-счётчики.

## Этап 7. Финальная сборка
Подготовлен ZIP-проект, README, workflow GitHub Pages и документы защиты.
