# Dropnetgaming CS2 demo

Готовый учебный сайт на React + Vite + Express + SQLite.

## Запуск

```bash
npm install
npm run dev
```

Открой сайт в браузере:

```txt
http://localhost:5173
```

API и база запускаются автоматически на:

```txt
http://localhost:3001
```

## Админка

В верхнем меню нажми `Админка` / `Admin`.

В админке можно:
- смотреть игроков из SQLite;
- добавлять игроков;
- смотреть и добавлять матчи;
- смотреть и добавлять турниры;
- удалять записи.

## Где база данных

После первого запуска появится файл:

```txt
data/dropnetgaming.sqlite
```

Это локальная база SQLite.
